# AgentGrid (Deutsch)

Viele KI-Coding-Agenten nebeneinander, jeder mit eigenem Account: Claude Code, Codex, Kimi, DeepSeek, GLM, Qwen, Grok und lokale Ollama-Modelle in einem schlichten schwarz-weißen Kachel-Terminal für macOS. Kein Ausloggen, kein Account-Wechsel.

- Beliebig viele Claude-Code- und Codex-Accounts parallel (eigener Config-Ordner pro Kachel)
- Eigene Chat-Fenster für DeepSeek, Kimi, GLM, Qwen, Grok, OpenAI, Anthropic und Ollama direkt über deinen API-Key; optional als Coding-Agent (opencode)
- Chat-Webseiten als Kacheln, jede mit eigenem Login
- Fenster einzeln verschieben (auf ein anderes ziehen = tauschen) und in der Größe ändern; API-Keys liegen verschlüsselt im macOS-Schlüsselbund

Installation und Details: siehe [README.md](README.md).
